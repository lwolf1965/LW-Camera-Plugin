# LW Camera Plugin

🇬🇧 [English version](README.md)

**Камера стыковки для Space Engineers 2.** Сядьте в кабину, нажмите **Alt+Home** и смотрите из коннектора своего
корабля, пока стыкуетесь. Колесо мыши приближает. Когда вы берёте турель под управление, вид переходит на её ствол.

Клиентский плагин для [Pulsar](https://github.com/SpaceGT/Pulsar). Работает только на стороне клиента: в мире ничего
не меняется.

## Возможности

| | |
|---|---|
| **Камера стыковки** | Каждый коннектор корабля, которым вы управляете, — камера. Неподвижный вид того, что перед коннектором; осматриваться нельзя. |
| **Управление по камере** | В камере стыковки W летит туда, куда смотрит камера, а верх экрана — это верх корабля, с какой бы стороны ни стоял коннектор. |
| **Приближение колесом** | От 80° до 6°, как у блока камеры в SE1. |
| **Камера турели** | Возьмите турель под управление — и вид будет от её ствола: мышь наводит, колесо приближает, ограничения углов турели действуют. Свободное наведение есть только у турелей. |
| **Необязательный тег** | `[CAM]` в названии коннектора задаёт имя камеры; `[CAM 2]` выносит её на 2 м вперёд. |
| **Дальность турелей** | Дальность автонаведения, дальность боеприпасов и разброс оружия игры. См. [Дальность и точность турелей](Docs/UserManual.ru.md#4-дальность-и-точность-турелей). |
| **13 языков** | Настройки показываются на языке игры. |
| **Безопасно** | Использует штатную подмену камеры игры. Выход из кабины, смена грида или уничтоженный коннектор возвращают обычный вид. |

Другие блоки в этой версии камерами не являются.

## Быстрый старт

1. Установите плагин и запустите свой мир.
2. Сядьте в кабину корабля с коннектором и нажмите **Alt+Home**. Теперь вы смотрите из коннектора.
3. Колесо мыши приближает, **Alt+PageDown** / **Alt+PageUp** переключают коннекторы, **Alt+Home** или **Esc** —
   назад.

Клавиши меняются в настройках плагина (Pulsar → плагин → кнопка настроек).

## Установка

Из списка плагинов Pulsar, когда плагин будет опубликован в PluginHub-SE2. До тех пор: соберите его сами (ниже)
и укажите `Pulsar` в `Directory.Build.props.user`, тогда DLL после каждой сборки копируется в `Pulsar/Modern/Local`.

## Сборка

Нужно: .NET 10 SDK, Space Engineers 2, Pulsar.

1. Создайте `Directory.Build.props.user` по образцу `Directory.Build.props.user.example` и укажите `Game2`
   (папка с `SpaceEngineers2.exe`) и при желании `Pulsar`.
2. `dotnet build` (или соберите `LwCameraPlugin.sln` в Rider / Visual Studio).
3. Тесты логики, не зависящей от игры: `dotnet run --project tests`.

## Как это работает

У камеры отрисовки игры (`CameraComponent`) есть публичная подмена положения и свой угол обзора — их использует
сама игра для свободного обзора наблюдателя и прицеливания. Плагин каждый кадр ставит подмену от точки коннектора
(центра его стыковочной поверхности) и снимает её, когда вы выходите из камеры стыковки. Всё ведёт постфикс Harmony
на `Session.Update`. Небольшие префиксы переводят управление в оси камеры стыковки, замедляют наведение турели при
приближении, дают выйти из камеры по Esc и очищают состояние плагина при закрытии мира; ни один метод игры не
заменяется.
